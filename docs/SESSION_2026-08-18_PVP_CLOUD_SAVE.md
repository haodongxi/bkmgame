# 会话总结：PvP 准备广场、云存档与联机稳定性

Created by haodongsheng

日期：2026-08-18

## 本次完成

### PvP 准备广场

- 新增 PvP 临时队伍准备广场。
- 从单机队伍读取时只取前 4 只宝可梦，单机第 5、6 只不上传。
- 支持调整首发顺序、队伍顺序、技能和携带物。
- PvP 调整免费，不扣金币、不消耗道具、不调用单机存档保存。
- 调整技能改为单机详情页风格，显示属性、类别、威力、命中、PP 和技能效果。
- 增加宝可梦 PvP 详情：单机等级 → PvP Lv100、能力值、个体值、糖果、称号、携带物和技能。
- PvP 规则明确显示：等级统一 Lv100，HP ×5。

### PvP 属性同步

- 上传队伍时同步个体值、糖果加成和装备称号加成。
- 服务端权威计算同步应用糖果与称号加成，避免客户端显示与实际战斗不一致。
- HP 糖果加成计入 Lv100 基础 HP 后再应用 PvP HP×5。
- 单机队伍本身的等级、能力值、糖果和称号数据不被修改。

### 云存档

- 云存档上传/下载接入账号系统。
- 单机存档码导出/导入界面增加云存档上传和下载按钮。
- 未登录时在单机界面直接弹出登录/注册框，不再跳转联机页面。
- 登录或注册成功后自动继续之前的上传/下载操作。
- 云存档按用户 ID 保存到服务端 SQLite `saves` 表。
- 下载覆盖本地存档前需要确认；失败不会破坏本地存档。
- 密码不保存在浏览器，只保存服务端加盐哈希。

### 快速匹配稳定性

- 修复匹配成功后客户端仍停留在准备广场的问题。
- 进入联机页面时自动恢复正在进行的匹配或对战。
- 快速匹配遇到服务端提示“对局进行中”时，自动查询并恢复已有房间。
- 支持页面刷新或短暂断线后的对局恢复。

### 其他

- 耿鬼学习面调整为催眠术、食梦、污泥炸弹、暗影拳等更符合幽灵/毒特色的技能。
- 重生药价格由 10 万金币调整为 50 万金币，并同步更新测试。
- `origin/codex/bkm-remote-battle` 已合并到客户端 `main`。

## 保持不变的原则

- PvP 准备和战斗不写入单机存档。
- PvP 消耗性道具只作用于服务端对战副本。
- 单机存档码功能继续保留，云存档作为账号同步方案。
