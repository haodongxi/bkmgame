## 一、目标

为《宝可梦：关都篇（纯文字像素版）》（bkmgame）增加玩家对战（PvP）能力：

- **bkmserver**：Python 3 标准库实现的对战服务端（账号 / 房间 / 匹配 / 服务端权威回合制战斗 / 战绩）
- **bkmgame**：新增联机对战客户端入口（登录、队伍上传、建房 / 匹配、战斗界面）

## 二、代码与仓库

| 仓库 | 分支 | 说明 |
| --- | --- | --- |
| haodongxi/bkmserver | main（最新） | 服务端 + 部署脚本 + HTTPS 支持 |
| haodongxi/bkmgame | codex/bkm-remote-battle | 联机客户端（main 未改动） |

## 三、服务端功能（bkmserver）

- 账号：注册 / 登录 / token（PBKDF2 加盐）
- 队伍：1-4 只、等级 1-100、性格 / 个体值 / 携带物 / 招式合法性校验；客户端提供一键测试队伍
- 房间：私有房（6 位码）、凭码加入、离开；随机匹配队列（入队前校验队伍、同账号禁重复入队、异常对手不阻塞他人）
- 对战：经典回合制（先制招 > 速度 > 平速随机）、Gen3 伤害公式、17 属性克制、天气、异常、守住 / 畏缩、多段 / 固定伤害、反伤、回复、换人 / 道具占回合、倒下选下一只、同归于尽平局、认输立即结算
- 战绩：胜负平、简化 ELO、排行榜、最近 50 场回放（内存）
- 传输：HTTP 轮询（客户端 900ms）+ SSE 事件流端点
- 超时兜底：回合 45s 随机出招、换人 60s 自动选第一只、断线 90s 判负
- 历史回退：回合 10s 限时 / pass 指令曾实现，用户要求回退，已恢复 45s 随机出招

## 四、客户端功能（bkmgame 联机分支）

- 入口：标题页不显示；地图操作面板显示且**仅城镇**出现
- 大厅：服务器地址（默认 `https://bkmapi.duckdns.org:8787`，本机 127.0.0.1/localhost 自动同源）、登录 / 注册、上传当前队伍 / 生成测试队伍、建房 / 凭码加入 / 快速匹配
- 战斗：复用像素 UI，事件流日志、出招 / 道具 / 换人 / 认输、倒下选下一只
- 登录态用 sessionStorage 按窗口隔离（本机双开各登各的账号即可匹配）
- 修复过的关键坑：匹配排队轮询被空 roomId 提前退出、旧已结束房间遮挡队列状态、同账号重复匹配顶号、`pending_switch` 判定错误

## 五、部署与线上环境

- 腾讯云服务器：`81.69.228.20`（Ubuntu 26.04，Python 3.14）
- 服务：systemd `bkmserver`，监听 `0.0.0.0:8787`，开机自启、崩溃自愈
- 线上地址：**`https://bkmapi.duckdns.org:8787`**
  - DuckDNS 免费子域名 `bkmapi.duckdns.org`（DNS 指向服务器）
  - Let's Encrypt 证书经 **DNS-01** 签发（腾讯云对未备案域名拦 80/443，DNS 验证 + 8787 非标端口绕开）
  - 证书有效期 90 天，certbot.timer 自动续期；续期钩子自动复制证书并重启服务
  - 证书副本：服务器 `/opt/bkmserver/.deploy/certs`，续期钩子 `/opt/bkmserver/.deploy/after-renew.sh`
- 游戏页：用户自行部署（GitHub Pages），需使用 `codex/bkm-remote-battle` 分支的 `js/remote.js`
- 部署脚本：`bkmserver/scripts/deploy.sh`（`push` / `status` / `logs`）
  - `push` 上传代码并重启，保留服务器上的 `data/players.json` 战绩与 `.deploy/` 证书

## 七、次日异地使用

1. 打开 GitHub Pages 游戏页 → 「🛰️ 联机对战」→ 服务器地址默认 `https://bkmapi.duckdns.org:8787`
2. 注册 / 登录 → 上传队伍（或一键生成测试队伍）→ 建房发码 / 快速匹配
3. 更新服务端：拉取 bkmserver → `./scripts/deploy.sh push`（需要本机 SSH 公钥已加入服务器 authorized_keys）

## 八、注意事项

- 服务器 SSH：本机 Mac 公钥已加入 `authorized_keys`；服务器密码建议尽快修改
- DuckDNS token 保存在服务器 `/opt/bkmserver/.deploy/`（chmod 700），**未写入仓库**
- bkmgame 的 main 未做任何修改；联机功能全部在功能分支
- 若浏览器之前保存过旧服务器地址，清空输入框或删除 localStorage 的 `bkm_remote_server` 即可使用新默认
