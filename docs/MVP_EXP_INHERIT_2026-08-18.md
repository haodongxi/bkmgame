# MVP：经验继承与替换培养（2026-08-18）

Created by haodongsheng

## 一、目标

玩家抓到更适合培养的新宝可梦时，可以把旧首发的培养进度交给新宝可梦，避免新成员从低等级重新练起，同时不复制培养资源。

## 二、MVP 规则

- 入口：电脑箱中宝可梦的「继承经验」按钮。
- 目标：从队伍选择一只旧宝可梦 A，再选择电脑箱中的新宝可梦 B。
- 执行后 B 替换 A 进入队伍，A 被传送给大木博士并从存档移除，避免经验复制。
- B 继承 A 的目标等级和当前等级内经验进度；进度会按 B 的成长曲线封顶在目标等级内，避免跨成长曲线意外多升一级；B 不会降级，若 B 等级不低于 A 则不允许继承。
- B 按自身成长曲线重新计算累计经验，复用 `grantExp` 处理逐级升级、学习面、待学招和等级进化。
- A 的携带物退回背包；B 的携带物保持不变，不自动覆盖或转移。
- 不继承：个体值、性格、羁绊、糖果加成、闪光状态、技能、异常状态和进化形态。
- 继承过程沿用电脑箱传送费用：费用为 A 等级²，最低 1000 金币；不额外产出万能经验和属性糖果。
- A 上锁、B 上锁、金币不足、队伍为空或目标等级不高于 A 时，操作被拒绝。
- 必须二次确认，确认文案明确 A 会被传送且不可恢复。

## 三、边界处理

- B 与 A 成长曲线不同：只转移 A 当前等级内的经验进度比例，不直接复制 A 的累计经验数值。
- B 连升多级：学招队列继续按稳定 `uid` 关联并去重；进化按 B 自身进化链逐级触发。
- B 已有携带物：保持 B 的道具；A 的道具单独退回背包。
- B 已满级：不需要继承，直接提示；A 不发生变化。
- 继承失败时不扣钱、不移除 A/B、不改变携带物。
- 该功能只影响单机队伍和存档；PvP 必须重新确认上传队伍后才使用新等级数据。

## 四、暂不纳入

- 不支持保留 A 的同时复制经验给 B。
- 不支持 A/B 互换等级。
- 不自动转移技能、羁绊、个体值、性格或携带物。
- 不改变现有万能经验池和普通电脑箱传送的产出规则。

## 五、验收标准

- 普通低等级 B 可继承高等级 A，并保持 B 的个体值/性格/羁绊/携带物。
- A 被移除，A 的携带物回到背包，B 的原携带物不变。
- 升级过程中学招和进化正常，待学招不会错绑到其他宝可梦。
- 金币不足、锁定、目标等级不合格、满级和失败场景均无副作用。
- 旧存档无需迁移，新增逻辑不新增必填存档字段。
