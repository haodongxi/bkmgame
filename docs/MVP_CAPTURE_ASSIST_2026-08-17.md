# 抓宠辅助功能 MVP 方案（2026-08-17）

## 目标

为玩家提供一个稳定、可理解、不会破坏常规战斗平衡的抓宠辅助机制：

- 当玩家想捕捉野生宝可梦时，可以主动使用专门手段把目标压到 `1 HP`
- 该效果不能变成全局默认规则，避免所有野战都自动变成“锁 1 血”
- 该效果要自然融入现有 `招式 / TM / 商店 / 图鉴合集 / 测试` 体系

## 最终方案

采用 `新招式 + 新 TM` 的形式实现。

### 招式

- 名称：`点到为止`
- 属性：`普通`
- 分类：`物理`
- 威力：`40`
- 命中：`100`
- PP：`40`

### 核心效果

- 仅当目标为 `野生宝可梦` 时生效
- 若这一下原本会让目标 `HP <= 0`，则改为让目标保留 `1 HP`
- 对训练家战、道馆战、火箭队战、无尽之塔、超越之塔全部无效

## 为什么采用这个形态

### 不做成全局默认规则

如果任何攻击都会自动把野怪留到 `1 HP`，抓宠流程会失去选择和节奏，普通野战也会被一起改坏。

### 不优先做成常驻道具

常驻携带物会变成抓宠标配，容易压过其它携带物的选择价值。

### 选择 TM + 招式 的原因

- 玩家理解成本最低，符合宝可梦直觉
- 有明确代价：需要学会这招、占一个招式位
- 可以直接复用现有 `TM / 招式图鉴 / 道具图鉴 / 商店` 结构
- 后续如果想扩展成 NPC 奖励、野外支线、专属道具，也不会推翻 MVP

## MVP 投放方案

### 道具

- 名称：`TM点到为止`
- 类型：`tm`
- 对应招式：`点到为止`

### 获取方式

MVP 先放进商店货架：

- 解锁门槛：`4 枚徽章`
- 价格：`8000 金币`

理由：

- 太早给会削弱前中期抓宠资源管理
- 太晚给会让它失去“补图鉴助手”的价值
- 放在商店最省实现成本，也最容易被玩家发现

## 详细规则

### 生效条件

必须同时满足：

- 玩家主动使用的招式是 `点到为止`
- 当前战斗类型是 `wild`
- 本次伤害会导致目标倒下

### 不生效的情况

- 训练家战
- 道馆战
- 宿敌战
- 火箭队战
- 无尽之塔 / 超越之塔
- 回合结束的异常状态伤害
- 反伤、自伤、寄生种子、沙暴等非该招式直接造成的伤害

### 日志表现

当效果触发时，追加一条明确日志：

- `点到为止手下留情，波波留下了 1 点 HP！`

这样玩家能立刻理解：不是伤害算错，而是招式特效生效。

## 与现有系统的集成点

### 招式图鉴

`点到为止` 会自动进入招式图鉴，并显示专属效果文案。

### 道具图鉴

`TM点到为止` 会自动进入道具图鉴，并显示“让宝可梦习得招式：点到为止”。

### 商店

4 徽章后商店可见并可购买。

## MVP 实现范围

本次只做以下内容：

1. 新增招式 `点到为止`
2. 新增道具 `TM点到为止`
3. 商店 4 徽章解锁购买
4. 战斗中对野生宝可梦触发“留 1 HP”
5. 招式图鉴 / 道具图鉴自动展示
6. 逻辑测试 + 浏览器测试

## 本次不做

以下内容明确放到后续版本，不进入这次 MVP：

- 捕捉专属携带物
- 捕捉专属药水 / 喷雾 / 护符
- 抓宠专用 NPC 支线
- 限定宝可梦学习面筛选
- 多段攻击版“留 1 HP”特效
- 对异常状态收尾伤害的额外保护

## 验收标准

### 逻辑

- `点到为止` 对野生战致死时，目标保留 `1 HP`
- 同样的招式在训练家战不触发保底
- `TM点到为止` 可购买、可使用、可学会

### UI

- 商店显示 `TM点到为止`
- 道具图鉴显示 `TM点到为止`
- 招式图鉴显示 `点到为止`
- 战斗日志出现“留下 1 点 HP”的提示

## 后续扩展方向

如果 MVP 手感好，下一阶段可以考虑二选一：

### 方向 A：做深抓宠流派

- 新增捕捉专属携带物
- 新增提升扔球成功率的称号 / 道具
- 抓宠相关 NPC 支线

### 方向 B：保持轻量

- 只保留 `TM点到为止`
- 把它作为稳定的中期补图鉴工具，不继续叠复杂系统
